# Железо Орион-ПРО в ядре

Источники: `_ports.txt`, `modOrion.pas`, `ScrThrd.pas` из OriZEmu; `ports.inc`, `ROM1-3.20.asm` из romychs/Orion-PRO. Строки с пометкой **проверить** взяты из одного источника.

## Машина

Z80: 2,5 МГц при D5 порта 0A, иначе 5 или 10 МГц (пункт OSD). ОЗУ 512 КБ, 1 или 2 МБ. Страница 64 КБ, сегмент 16 КБ. Сегмент `s`: страница `s[7:2]`, адрес `{s[1:0], a[13:0]}`.

## Память процессора (порядок проверок как в `peekb` / `pokeb`)

| Адрес | Что отвечает |
|---|---|
| 0000–1FFF | ROM1 при 0A D4, запись теряется; иначе как окно RAM0 |
| 2000–3FFF | ROM2 при 0A D3, сегмент 8 КБ из порта 09, запись теряется; иначе как окно RAM0 |
| 0000–3FFF | O-128 и FB D7 = 0: сегмент FB D1..0 страницы FB D3..2; иначе при 0A D0 сегмент порта 04; иначе рабочая страница |
| 4000–7FFF | 0A D1: сегмент порта 05; иначе рабочая страница |
| 8000–BFFF | 0A D2: сегмент порта 06; иначе рабочая страница |
| C000–EFFF | рабочая страница |
| F000–FFFF ПРО | 0A D6: страница 7 (сегмент 31); иначе рабочая страница |
| F000–F3FF O-128 | страница 7, при FB D5 рабочая |
| F400–F7FF O-128 | порты, в ОЗУ не пишется |
| F800–FFFF O-128 | чтение страницы 7 (при FB D5 рабочей); запись только в порты F8–FA, в ОЗУ не идёт |

Рабочая страница: порт 08 в режиме ПРО, порт F9 в режиме O-128 (0A D7 = 1).

## Экран

Режим F8 (D4..D0): `0x000`, `0x001` моно; `0x01x` запрет; `0x100`, `0x101` 4 цвета; `0x11x` 16 цветов по ячейкам; `01 11x` псевдоцвет; `1x0xx` 3 бита RGB; `1x1xx` 4 бита RGBI. Для экрана `n`: база C000, 8000, 4000, 0.

В режимах D4 = 1 экранов два, D0 порта FA игнорируется. Плоскости: R = стр. 0 по базе, B = стр. 1 по базе, G = стр. 0 по базе + 4000, I = стр. 1 по базе + 4000. Страницы 0 и 1 лежат в двух линиях SRAM, поэтому 16-битное чтение отдаёт R и B за раз, а второе G и I.

Палитра: индекс `{G, R, B, I}`, 4 бита на канал, уровень расширяется до 8 бит.

## Память SRAM (22 бита байтового адреса)

| Адрес | Размер | Что |
|---|---|---|
| 000000–1FFFFF | 2 МБ | ОЗУ: `{page[4:1], a[15:0], page[0]}` |
| 200000–23FFFF | 256 КБ | ROM-диск |
| 240000–30CFFF | 820 КБ | кэш диска A |
| 30D000–3D9FFF | 820 КБ | кэш диска B |
| 3E0000–3EFFFF | 64 КБ | ROM2 |
| 3F0000–3F1FFF | 8 КБ | ROM1 |

## Отличия от настоящей машины

- Регистры настройки 03, 07, 0B не сбрасывают порты.
- Запрет отключения ROM1 до первой записи в FB не сделан: BIOS его снимает сразу.
