# Бэклог Орион-ПРО

## Решения пользователя

- **Публикация и GitHub.** Репозиторий пока только локальный: создание на GitHub требует подтверждения пользователя.
- **ROM1 и ROM2 3.21 в репозитории и в `.kg`.** Разрешение на M2 и один ROM-диск (2026-11-05) относилось к core-orion128. У OriZEmu нет файла лицензии. Решить до публикации.

## Проверить по ходу работ

- Режимы 3 и 4 бита: порядок плоскостей взят из `ScrThrd.pas`, на программах не проверен.
- Уровни палитры по умолчанию заданы таблицей BIOS `PALTAB`.
- Какой объём ОЗУ видит BIOS при зеркалах страниц.
- Прерывания: ROM1 использует `IM 2`, вектор и источник (ISRTAB, 8 записей) ещё не разобраны.

## Идеи

- Два кэша дисков занимают 1640 КБ. Без них ОЗУ могло бы быть 3 МБ.
